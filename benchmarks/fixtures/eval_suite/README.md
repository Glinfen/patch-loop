# Evaluation Service

This fixed repository models ten small service concerns.

- Authentication covers bearer token verification and demo password hashing.
- Billing covers tax-inclusive invoice totals and percentage discounts.
- Pagination covers one-based page slicing and next-offset cursors.
- Cache behavior covers namespaced keys and TTL expiration.
- Notifications cover email envelope formatting and urgent delivery channels.
- Inventory covers stock reservations and reservation release.
- Users covers normalized email addresses and profile display names.
- Reports covers summary metrics and single-row CSV export.
- Scheduler behavior covers future timestamps and exponential retry backoff.
- Validation covers lowercase slugs and positive order quantities.
