# ADR-014：以事实槽和来源权威管理语义记忆

## 状态

已接受。

## 背景

LCM-03 的长期晋升记录能保存阶段结论，LCM-04 能保存完整执行情景，但两者都不能回答“某个符号当前的值是什么”，也不能在文件读取、补丁、模型推断和测试证据互相冲突时选择唯一的活动版本。只按文本相似度召回会同时暴露旧值和新值，使长任务重新采用已经过期的事实。

模型辅助抽取还存在证据越权风险：模型可以生成有用候选，但不能仅凭自己的陈述把事实标记为已验证。

## 决策

### 类型化事实与事实槽

- 语义记录复用 `MemoryRecord`，并以 `semantic_schema=1.0` 区分 LCM-03 的非类型化阶段摘要。
- 首版事实类型为任务约束、禁止事项、代码符号、代码观察、计划证据、验证结果和推断。
- 事实槽由作用域、作用域 ID、事实类型、规范化 subject 和 predicate 的稳定哈希确定；value 不进入槽，因此同一命题的不同值会发生冲突。
- value 使用 Unicode NFKC、空白折叠和大小写无关的比较值去重。超长字段以“前缀加完整内容哈希”有界化，避免大文件观察让记忆写入失败或产生静默碰撞。

### 来源权威

权威等级固定为：

1. `verified=100`：成功测试或命令直接验证。
2. `user_asserted=80`：用户明确约束或禁止事项。
3. `observed=50`：文件读取、diff 或工具失败结果。
4. `inferred=20`：计划证据和模型辅助抽取。

模型辅助抽取器是可插拔接口。无论插件声称什么状态，进入核心解析器时都强制降为 `inferred`，置信度上限为 0.6。

### 冲突与替代

- 同槽同值且新权威不高于当前值时抑制重复记录。
- 同槽同值但权威更高时创建新记录并替代旧记录，从而保存证据升级。
- 同槽不同值且新权威不低于当前值时，创建双向、无环替代链；默认查询只返回新的活动事实。
- 低权威冲突仍以 `invalidated` 记录保留，并指向冲突的活动事实，但不能进入默认召回。
- 来源与旧、新记录在一个 SQLite 批次事务中提交，替代链不会部分生效。

同权威采用较新的直接观察覆盖较旧观察，因为代码工作区会随补丁推进；高权威旧事实仍能阻止低权威猜测覆盖。

### 抽取与查询

确定性抽取器处理任务目标、完成计划证据、带行号的文件读取、累计 unified diff、测试和命令结果。来源使用稳定 call/path ID，保存步骤、路径和脱敏证据哈希。

`MemoryQuery.fact_types` 与 `epistemic_statuses` 提供结构化过滤；一旦指定语义过滤器，非类型化或非语义记录不匹配。状态默认仍只有 `active`。

## 后果

Runtime 能在离线、无模型抽取器的情况下持续构建类型化事实，测试通过会把补丁观察提升为已验证事实。完整历史仍可审计，而普通召回不会同时得到相互冲突的活动版本。checkpoint 保存累计计数，恢复时从 SQLite 活动记录重建冲突解析状态。

代价是首版确定性解析只识别有限的赋值语句和行级观察，不尝试完整 AST 或跨文件数据流分析。LCM-06 将负责跨层召回与预算，LCM-07 再合并重复证据；两者都必须保持本 ADR 的状态与权威不变量。
